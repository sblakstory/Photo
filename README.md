# Seblak Story Photobooth PWA v1.0.1

Upload semua file ke GitHub, aktifkan GitHub Pages (Settings > Pages > Deploy from a branch > main / root), lalu buka URL HTTPS di Samsung Tab A9 dan pilih Install app.

Fitur: kamera depan/belakang atau webcam USB yang didukung browser, countdown 3/5/10 detik, 3/4 foto, frame Seblak Story, simpan PNG, dan cetak melalui dialog cetak Android.

Cetak langsung Bluetooth ESC/POS belum tersedia. Integrasi langsung memerlukan model printer EPPOS dan jenis koneksinya.
